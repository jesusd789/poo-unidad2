# POO - Unidad 2: Modificadores de acceso en Java

Actividad individual de Programación Orientada a Objetos (Unidad 2).

| Taller | Tema | Carpeta |
|--------|------|---------|
| 4 | Modificador `private` | `taller4-private` |
| 5 | Modificador de paquete (`default`) | `taller5-default` |
| 6 | Modificador `protected` | `taller6-protected` |

## Estructura de cada taller
- `src/` : código que compila (ejemplos correctos, malas prácticas y ejercicios resueltos).
- `errores_intencionales/` : código que NO compila a propósito, para observar los errores.
- `ejecutar.sh` : compila y ejecuta los ejemplos y ejercicios.
- `errores.sh` : muestra los errores de compilación esperados.

## Cómo ejecutar
Requisito: JDK 11 o superior.

    cd taller4-private && bash ejecutar.sh && bash errores.sh
